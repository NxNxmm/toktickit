## Reflection

One big takeaway from this lab was learning how to deal with the AI's limits. To make sure the AI didn't invent its own rules, I had it re-read our spec files in docs/lab-03/ with almost every prompt.

The downside was that we ran out of memory (token limits) pretty often. I had to open new chat windows quite a bit, which meant waiting for the AI to scan the project and re-read the docs again. But it was totally worth the extra effort—keeping the AI strictly tied to our specs meant the code it generated hit every single requirement without getting off track.
